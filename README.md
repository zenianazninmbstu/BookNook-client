📚 BookNook – A Small Online Library

BookNook is a small online library platform where users can discover books, manage their own book collections, and borrow books easily.

🔗 Live Website: https://book-nook-client-iota.vercel.app/

✨ Features

- Browse Books: Explore all available books in the library.

- Book Details: View detailed information about each book.

- User Authentication: Register and sign in securely.

- Add Books: Add new books to the online library.

- Manage My Books: View, edit, and delete books added by the logged-in user.

- Borrow Books: Borrow available books by selecting borrowing and return dates.

- My Borrows: View and manage personal borrowing records.

- Responsive Design: Access the website on desktop, tablet, and mobile devices.

🚀 Getting Started

1. Clone the Repository

git clone https://github.com/zenianazninmbstu/BookNook-client.git

2. Navigate to the Project Directory

cd BookNook-client

3. Install Dependencies

npm install

4. Run the Development Server

npm run dev

Open http://localhost:3000 in your browser to view the application.
